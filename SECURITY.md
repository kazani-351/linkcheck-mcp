# Security

Please report vulnerabilities privately through GitHub: the **Security** tab of this repository, then **Report a vulnerability**. Don't open a public issue for security problems.

In scope: anything that makes linkcheck return `SAFE` for a link it should flag, bypasses the owner-only checks, makes the server request something it shouldn't, or exposes a secret.

linkcheck is a hobby project maintained by one person, so replies may take a few days.
